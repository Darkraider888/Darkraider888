## 🌍 Waylo — Travel, Booking & Community

<div align="center">

### Discover trips. Book experiences. Travel together.

[![Waylo Repository](https://img.shields.io/badge/GitHub-Waylo-E50914?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Darkraider888/Waylo)
[![Waylo Live](https://img.shields.io/badge/Live-Demo-111111?style=for-the-badge&logo=render&logoColor=white)](https://waylo-darkraider888.onrender.com/feed)

</div>

**Waylo** is a university-focused travel-booking and community web application built using **Java 25, Spring Boot 4.1.1 and Thymeleaf**. It connects trip discovery, organizer applications, bookings, private trip chats and administration in one platform.

### ✨ Main Features

- Destination exploration, trip browsing and community posts.
- Student account registration, secure sign-in and password recovery.
- Trip Manager applications and trip-specific organizer approval.
- Booking and seat reservation workflows.
- **SSLCommerz Sandbox** checkout with server-side transaction verification.
- Private trip-group messaging for eligible confirmed travelers.
- Organizer chat moderation, administrative review and role-based permissions.
- Cloud-based image storage, database migrations and public-destination caching.
- Optional JWT-authenticated REST endpoints.

### ⚙️ Waylo Stack

`Java 25` `Spring Boot 4.1.1` `Spring Security` `Spring Data JPA` `Hibernate` `MySQL` `Thymeleaf` `Flyway` `Caffeine` `Cloudinary` `SSLCommerz Sandbox` `Brevo API` `Docker` `Render` `Aiven` `GitHub Actions`

```text
              Waylo • Spring Boot on Render
                          │
       ┌──────────────────┼──────────────────┐
       │                  │                  │
       ▼                  ▼                  ▼
   Aiven MySQL       Cloudinary       External APIs
  (JPA + Flyway)      (media)      (payments + email)
                          │
                          ▼
              Private Trip Community
```

> **Demo notice:** The payment integration uses **SSLCommerz Sandbox**, not real-money processing. On Render's free hosting tier, the first request after inactivity may load slowly.
